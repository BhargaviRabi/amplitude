## Summary / Explanation

This is a short, focused companion piece to the "Your data" lesson in "Getting Started with Amplitude Analytics": rather than explaining events/properties conceptually, it's a hands-on walkthrough of Amplitude's **Event Explorer** tool, showing how to inspect exactly which events and properties are already being tracked in a live project before you start building charts — i.e., how to audit your taxonomy rather than just define it.
